# UnifiedDrivingModel：局部二维加速度词表

`DrivingModel` 现在指向 `UnifiedDrivingModel`。输入仍为四帧单目图像、相机内参、导航指令、当前运动状态和帧间运动矩阵。

## 视觉与词表

视觉处理器有 12 层。同一帧的图像 Token 可双向交互；较晚帧可读取较早帧，较早帧不能读取较晚帧。导航和运动条件 Token 仅读取自己，其他 Token 可读取它们。寄存器和标注查询可读取全部 Token，其他 Token 不能读取这些查询。第 3、6、9、12 层图像特征用于网格恢复。

默认词表为 512 条未来 3 秒、10 Hz 的局部二维加速度序列 `[a_x,a_y]`。生成器从真实 CARLA 窗口中以近端加权笛卡尔轨迹距离做最远轨迹采样（FTS），对动作序列先去重，并以最接近零加速度的真实窗口作为首词；有效低速和静止窗口仍参与采样。两个加速度通道分别用成功场景的 250,000 个抽样窗口、全部 30 个时间步统计均值与总体标准差，按 `(a-mean)/max(std, 1e-3)` 标准化；词原型候选限制不影响这组统计。每个标准化数值使用 `π·a_norm·[1,2,4,8]` 的四频正余弦编码，再经线性层投影。词特征与导航条件、标准化当前局部二维速度及加速度的嵌入相加；不额外添加词 ID 或轨迹位置编码。

词序列经过两组交叉注意力和 FFN，再经过一组沿词轴压缩 K/V 的低秩自注意力和 FFN。共享线性头为每个词输出一个 logit，Sigmoid 给出概率。缓存生成时用样本的实际当前二维速度积分每个物理词，再与原始 GT 笛卡尔航点比较，将近端权重更高的轨迹距离最近词的索引存为 Top1；训练直接读取此索引，其他词的目标为零。对比 GT 新增碰撞、闯红灯停止线、历史运动突变、车道线跨越或车道边界越界风险的负词，其 BCE 权重为 1.2。

## 残差与积分

将标准化残差数据空间状态 `[30,2]` 展平，与选中词特征和当前条件特征拼接，线性投影后交给三组带 AdaLN-Zero 时间调制的 SwiGLU FFN。网络输出的是**标准化二维加速度残差终点**。缓存生成时先选 Top1，再以物理单位计算 `r=GT 加速度 − Top1 词加速度`，最后使用词表文件中的 `residual_mean`、`residual_std` 保存 `(r-residual_mean)/residual_std`；每条样本只保存这一个 `[30,2]` 残差，不保存 GT 加速度或所有词的残差。残差均值与总体标准差由上述 250,000 个窗口按相同笛卡尔选词口径统计。训练时在同一数据空间内令 `x_t=(1-t)z+t r_norm`，其中 `z` 为高斯噪声，监督缓存的残差终点 `r_norm`；采样时由预测终点构成流更新。采样完毕后将残差逆标准化，加到词的物理加速度，再由**当前实际局部二维速度**逐步积分：`v_i=v_{i-1}+a_i Δt`，`p_i=p_{i-1}+v_i Δt`。词表保存的源初速度只供绘图使用。静止窗口不会因为曲率分母接近零被剔除。

正式动作词表只接受场景标注 `complete=true`、`failed=false` 且 `status=ok/max_frames` 的终止场景；失败碰撞场景和未终止的 partial 段在抽样前整场排除，因此不进入动作、运动状态或残差统计。当前数据中有 1,012 个符合条件的场景、84 个标记为碰撞失败的场景。250,000 个成功场景抽样窗口中，231,067 个满足词原型的加速度和加加速度连续性限制，FTS 从中选出 **512 个互异**的 `[30,2]` 物理词。成功场景的全部抽样窗口仍参与标准化与残差统计，训练 GT 不因词表候选限制而丢弃。词表同时保存 `actions`、使用全体窗口通道均值/标准差计算的 `normalized_actions`、动作/残差/运动状态统计，以及每个词的源起点二维速度与源轨迹；模型直接读取标准化词，绘图使用源轨迹。旧场景缺少逐窗口碰撞事件，因此只能按场景级失败标注排除碰撞，不能识别成功场景中曾恢复的碰撞；候选连续性约束也不能充当碰撞标签。首词保留近零加速度静止模式。100 个真实场景中检查了 27,897 个窗口，其中 16,812 个窗口的初始速度低于 0.05 m/s，未因低速剔除；积分重建航点的最大误差约 `9.6e-7 m`。这只验证数据表示与积分实现，不代表模型已经训练收敛或闭环驾驶通过。

生成词表：`python -m data.trajectory_vocabulary.run --actions`。训练前须使用新版 `v13-top1-standardized-residual` 驾驶缓存；它保存 Top1 词索引和对该词的标准化物理加速度残差，帧索引及切片准备仍整场排除失败记录。
